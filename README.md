В проекте пять работ: форма обратной связи, записная книжка, роутинг, шаблоны и статьи. Используются PHP 8.2+, PDO и MySQL. Код блога находится в `app/`, первые две работы — в `lab1/` и `lab2/`.

## Запуск

1. Создать базу MySQL и импортировать `sql/01_schema.sql`, затем `sql/02_seed.sql`.
2. Скопировать `config.example.php` в `config.php` и заполнить данные подключения.
3. В папке проекта выполнить:

```sh
php -S 127.0.0.1:8080 router.php
```

Открыть http://127.0.0.1:8080/. Нужны расширения `pdo_mysql`, `mbstring` и `openssl`.
