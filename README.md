Сайт: [polykeklab.alwaysdata.net](https://polykeklab.alwaysdata.net/)

В проекте пять работ: форма обратной связи, записная книжка, роутинг, шаблоны и статьи. Используются PHP 8.2+, PDO и MySQL. Код блога находится в `app/`, первые две работы — в `lab1/` и `lab2/`.

## Запуск

1. Создать базу MySQL и импортировать `sql/01_schema.sql`, затем `sql/02_seed.sql`.
2. Скопировать `config.example.php` в `config.php` и заполнить данные подключения.
3. В папке проекта выполнить:

```sh
php -S 127.0.0.1:8080 router.php
```

Открыть http://127.0.0.1:8080/. Нужны расширения `pdo_mysql`, `mbstring` и `openssl`.

## Хостинг

Сайт размещён на alwaysdata. Для установки нужно загрузить файлы и `.htaccess` в папку PHP-сайта, импортировать SQL и настроить серверный `config.php`. Для красивых URL нужен Apache с `mod_rewrite`.

Проект можно разместить в подпапке. Если адреса определяются неправильно, указать её в `base_path` в конфигурации.

Пароли и локальная база исключены из Git через `.gitignore`. Логотип взят с сайта Московского Политеха.
