## Ограничения и оставшиеся действия

1. Apache/.htaccess и фактическое развёртывание в подпапке **не проверены на живом Apache**. Проверены формирование префикса и HTTP-маршруты через PHP development router. На хостинге нужно проверить rewrite и запрет чтения конфигурации/SQL.
2. alwaysdata и GitHub **не настроены и не опубликованы**: нужны ваш аккаунт, репозиторий, доступ к загрузке и параметры MySQL. Пошаговые инструкции есть в README.
3. Референс не открылся сетевым инструментом. Его пять разделов и сценарии **не удалось изучить**. Исходники референса не скачивались и не копировались; использованы текстовое ТЗ, приложенный скриншот и официальный логотип университета.
4. Удаление в записной книжке намеренно выполняется выбором GET-ссылки по заданию преподавателя, с токеном сессии и пояснением на странице. Для использования за пределами учебного стенда следует перейти на POST и добавить авторизацию.
5. Контакты не защищены авторизацией, которой нет в задании. Публичную учебную копию используйте только с вымышленными данными.

## Запуск сохранённой тестовой среды

В обычной среде достаточно своего MySQL и `tools/serve.ps1`. Если хотите использовать именно созданную в этой сессии локальную тестовую базу после остановки процессов, запустите в отдельном терминале:

```powershell
& 'C:\OSPanel\modules\MySQL-8.0\bin\mysqld.exe' --no-defaults --basedir=C:/OSPanel/modules/MySQL-8.0 --datadir=C:/PHP-Labs/.runtime/mysql --bind-address=127.0.0.1 --port=3307 --mysqlx=OFF --console
```

Это изолированный учебный экземпляр с пустым локальным паролем root; он не предназначен для хостинга. База уже импортирована, повторно запускать setup_test_db.php не нужно. Затем в другом терминале выполните `powershell -ExecutionPolicy Bypass -File tools/serve.ps1` и откройте http://127.0.0.1:8080/. Остановить сервер PHP можно Ctrl+C, MySQL — через mysqladmin shutdown, направленный на этот локальный экземпляр.
